# 國情群青傳：250階與國情群青鬥

## 遊戲內容

- 619題、九類各5題的入門試煉、修行、秘笈、六名對手及七張內嵌插圖。
- 玩家及六名對手各有250階成長，前10階門檻沿用舊版。第11–250階繼續提升，特殊能力設有合理上限。
- 「國情群青鬥」一對一連線：建立8位戰場編號，另一玩家輸入加入；每回合先答題再選招，雙方提交後同步結算。
- 每回合180秒；對手失聯時可在期限內重返。逾時時，已交招式的一方勝出；雙方皆未交招則和局。可以主動認輸。
- 勝方獲一次秘笈三選一，記錄最近300場對手、勝負、時間、回合數、雙方階段及獎勵狀態。
- 舊存檔可以匯入；未完成的舊決戰保留原數值。戰績與角色一同匯出。

## 直接使用HTML

`index.html` 已內嵌全部題庫、程式及插圖，單人模式可直接用瀏覽器開啟，毋須安裝套件。

雙人模式需要共用的連線服務，不能只靠兩份離線HTML互通。下載版預設連接原遊戲的線上服務。如果該服務仍設為私人，其他玩家不能連入；必須先開放網站訪問，或按下述方式自行運行服務。

## 自行運行完整連線版

需要 Node.js 22.13以上；本版本已在Node.js 24測試。不需npm安裝第三方套件，也不使用AI API。

在本資料夾開啟終端機，依次執行：

```sh
node scripts/build.mjs
node scripts/dev.mjs --port 4173
```

再以瀏覽器開啟 `http://localhost:4173/`。

若其他設備與伺服器在同一網絡，可在其他設備開啟 `http://伺服器的區域網絡IP:4173/`，並確保設備能連到此連接埠。由這個服務提供的遊戲會自動使用同一服務同步戰場。

本機戰場資料位於 `.local/duels.sqlite`。正式部署採用D1資料庫，schema見 `drizzle/0000_duel_rooms.sql`；完整Worker產物為 `dist/server/index.js`，需要名為 `DB` 的D1 binding。正式資料庫需先套用SQL migration。不要把 `.local` 或真實玩家存檔上傳至公開程式碼庫。

## GitHub／其他寄存服務

只將 `index.html` 放在GitHub Pages，可提供遊戲前端；跨設備群青鬥仍須連到可使用的API服務。若要獨立寄存整套服務，需要部署後端程式及資料庫。

如果自行更換連線服務，可修改 `web/duel.js` 的 `DUEL_ORIGIN` 後重新build。由本後端直接提供的頁面會自動使用該頁面的來源網址。

## 檔案結構

- `index.html`：可直接開啟的完整前端。
- `web/`：原始前端、雙人對戰介面及樣式。
- `server/`：權威戰場結算及API，並非讓任一玩家的瀏覽器決定勝負。
- `scripts/build.mjs`：產生HTML及正式Worker。
- `scripts/dev.mjs`：本機／區域網絡服務。
- `drizzle/`：資料庫migration。
- `tests/`：同步、身份、重複提交、逾時、平手、獎勵、250階及存檔測試。

檢查：`node --test tests/*.test.mjs`。建立後的HTML位於 `output/index.html`。

戰場伺服器保留約7天的房間資料，之後會在建立新戰場時清理。玩家的本機戰績不受此清理影響，亦可用JSON備份。
